# Almaz Tour · Рождественская Европа

Отдельный сайт и локальный Git-репозиторий в Almaztournewyeartour. Next.js 16.2.10, React 19, TypeScript. Интерфейс перенесён из https://happytour-three.vercel.app/ по запросу заказчика: геометрия разделов, тёмная бирюзовая палитра, золотые акценты, стеклянные CTA, карта с наклоном и увеличением, программа и FAQ.

## Запуск

```sh
npm install
npm run dev
```

http://localhost:3001. Production: `npm run build`, затем `npm start`.

## Редактирование

| Что                                    | Где                                           |
| -------------------------------------- | --------------------------------------------- |
| Текст секций                           | `src/data/reference-copy.ts`                  |
| Программа 9 дней                       | `src/data/itinerary.ts`                       |
| FAQ                                    | `src/data/faq.ts`                             |
| Включённые услуги и стоимость          | `src/data/tour.ts`                            |
| Контакты и WhatsApp API                | `src/data/company.ts`                         |
| Городские фотографии и авторство       | `src/data/photos.ts`, `public/images/cities/` |
| Компоненты нового интерфейса           | `src/components/reference/`                   |
| Последовательность разделов            | `src/app/page.tsx`                            |
| Общие стили и точные размеры референса | `src/app/globals.css`                         |
| Шрифты и метаданные                    | `src/app/layout.tsx`                          |

Секции — серверные компоненты. Только карта, кнопки и раскрывающиеся блоки используют клиентский JavaScript. Стили референса сохранены локально, без Tailwind CDN и сторонних скриптов. Предыдущие компоненты в `components/sections` и `components/layout` сохранены, но на главной странице не используются.

## Данные Almaz Tour

Компания работает с 2018 года. Контакты взяты из основного проекта AlmazTour: +7 775 888 97 32, https://api.whatsapp.com/send?phone=77758889732, Астана, Достык 4, Festival Avenue.

Новый текст заказчик предоставит отдельно. Пока использована информация о туре и компании из существующих данных и презентации. Награды, лицензии, образование и 19-летний стаж другого организатора из референса не переносятся на Almaz Tour. Доступность спеццены, расписание поездов и перелётов подтверждаются при бронировании; гарантий выдачи визы и остатка мест нет.

Исходная презентация остаётся в `public/documents/almaz-tour-christmas.pptx`; на слайде 9 исходника осталось имя Нины Шахановой, поэтому перед рассылкой исходник следует отредактировать.

## Проверки

```sh
npm run lint
npm run build
```

Карта: наклон мышью, маячки, увеличение в native dialog, Escape и возврат фокуса. Программа: один раскрытый день, первый открыт по умолчанию. FAQ: независимое раскрытие ответов. Снег и декоративная анимация отключаются при prefers-reduced-motion. На мобильном экране доступна нижняя панель звонка и WhatsApp, как в референсе.

Публикация и удалённый GitHub-репозиторий отдельно; эта версия доступна локально.
