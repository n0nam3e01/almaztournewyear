# Almaz Tour · Рождественская Европа

Самостоятельный сайт для авторского тура 12–20 декабря 2026 года. Next.js 16.2.10, React 19, TypeScript и CSS Modules. Отдельный локальный Git-репозиторий, без зависимости от исходного проекта AlmazTour.

## Запуск

```sh
npm install
npm run dev
```

Откройте http://localhost:3001. Для production: `npm run build`, затем `npm start`.

## Источники и редакционные решения

- Структура и подробная программа: https://happytour-three.vercel.app/.
- Материалы компании и фотографии: `ALMAZ_TOUR_10_SLIDES_PRESENTATION_EXACT_INFO.pptx`.
- Логотип и контактные данные: исходный проект AlmazTour.
- Сопровождающая: Алия, 10 лет организует путешествия по Европе, 19+ лет в туризме (слайд 2).
- Спеццена 2 200 € для первых 3 участников, обычная 2 350 €; доступность спеццены подтверждает менеджер. Нет автоматически меняющегося или выдуманного счётчика мест.
- Включены оба круиза, в Париже и Амстердаме (слайд 9).
- В референсе упоминаются другая компания, её лицензия, дипломы и адрес. Они не приписываются Almaz Tour.
- Слайд 9 исходной презентации содержит остаточное имя «Нина Шаханова». На сайте сопровождающая заменена на Алию согласно слайду 2. Сам исходный PPTX сохранён без изменений; перед внешней рассылкой исправьте этот слайд в презентации.
- Лимит группы 10 взят из основного описания референса. В нём также есть противоречивое «3 из 8», поэтому живой остаток мест на сайте не показывается.
- Сроки подачи до 20 октября, гарантия выдачи визы, «экономия 900 €» и фиксация цены на 48 часов не подтверждены презентацией Almaz Tour и не обещаются посетителю.
- Расписание поездов и рейсов взято из программы референса и помечено как уточняемое при бронировании.

## Новогоднее оформление и анимация

Белая палитра, небольшие снежинки поверх страницы, деликатное появление разделов и переходы кнопок. Снег отключается при `prefers-reduced-motion`. Клавиатурное раскрытие программы и FAQ происходит без задержки.

Нарисованная карта перенесена из референса по запросу заказчика: `public/images/tour/christmas-route-map.webp`. Компонент `RouteMap.tsx` поддерживает увеличение, перемещение при увеличении, возврат к общему виду и лёгкий наклон мышью.

## Изображения

Главный экран использует именно фотографию, которую заказчик прислал и подтвердил в чате. Фотографии городов показываются через CSS-окна оригинальных слайдов, исходные файлы не обрезаются. Портрет подготовлен встроенным ImageGen из фотографии Алии на слайде 2 с сохранением лица, одежды и естественного вида; фон заменён на рождественский Кольмар. Все растровые файлы для сайта сохранены в WebP.

Промпт портрета: сохранить личность Алии со слайда 2, сделать естественный портрет в бежевой куртке и цветном шарфе на фоне рождественского Кольмара, без медведя, надписей и ретуши лица. Лицензирование предоставленных материалов остаётся у владельца.
