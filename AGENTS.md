# Almaz Tour Christmas Europe

Independent Next.js 16.2 project. Before changing framework APIs, read the relevant guide in `node_modules/next/dist/docs/`.

- Tour and company facts belong in `src/data/`; do not invent availability, legal credentials or promises about visas.
- Each section has its own component and CSS Module. Shared elements belong in `src/components/ui/`.
- WhatsApp uses the original AlmazTour API link, configured in `src/data/company.ts`.
- Use the company logo supplied by AlmazTour and presentation images. Preserve the identity of Aliya.
- Respect reduced motion, keyboard navigation, visible focus and touch target sizes.
- Run `npm run lint` and `npm run build` after substantial edits.
